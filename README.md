## About

Postdoctoral researcher at **LaTIM** (INSERM UMR 1101, Université de Bretagne Occidentale, Brest) 🔬.
PhD on deep learning for PET reconstruction and data correction ([thesis](https://theses.hal.science/tel-05465688)).
